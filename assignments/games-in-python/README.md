# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. The finished program should let a player guess letters, reveal the hidden word over time, and end with a clear win or lose result.

## 📝 Tasks

### 🛠️ Set Up the Word Game

#### Description
Create the core game data and display logic for a Hangman round.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Show the current progress of the hidden word in `_ _ _` format
- Use simple, readable variables and keep the game state easy to follow

### 🛠️ Handle Guesses and Game Endings

#### Description
Add the input loop that accepts guesses, updates the game state, and ends the game when the player wins or runs out of attempts.

#### Requirements
Completed program should:

- Accept letter guesses from the player
- Track and display incorrect guesses remaining
- Reveal correctly guessed letters in the word
- End when the word is fully guessed or attempts are exhausted
- Display clear win and lose messages
